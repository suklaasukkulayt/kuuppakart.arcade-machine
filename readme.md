# DIY ARCADE MACHINE + KuuppaKart 1  

This is the GitHub repository for the **DIY Arcade Machine** made for [Stardance](https://stardance.hackclub.com/projects/30991) and for the [**KuuppaKart 1**](https://play.unity.com/en/games/4a235e58-f486-49cd-8fb5-33baa10e1e9a/kuuppakart-1) driving game I made that is used for the Arcade Machine.  

## KuuppaKart 1:  
You can **download** KuuppaKart for **Linux** and **Windows** (64-bit) machines, or **play in your browser** from [here](https://play.unity.com/en/games/4a235e58-f486-49cd-8fb5-33baa10e1e9a/kuuppakart-1). You can find the **controls** at the [**Releases**](https://github.com/suklaasukkulayt/kuuppakart.arcade-machine/releases) tab or in the **Unity Play** description.  
I made this game in coding class a while back and now I updated it for the DIY Arcade Machine.

### KuuppaKart features:
- AI opponent
- 3 difficulties
- FOV changer, first person and third person mode
- One level
- Halloween update
- Speedometer, boost and lookback
- Weirdest controls ever, because it's made for the DIY arcade machine
- Pause menu with graphics settings
- And more!

## DIY Arcade Machine:  
**Made by** me and [@MakkonenHugo](https://github.com/MakkonenHugo).  
This machine **made from** **just scrap** I found around the house, that's why the part list is super weird, and you aren't really supposed to buy anything I have linked. **Use your creativity!**  
**More info** about the project can be found [**here**](https://stardance.hackclub.com/projects/30991)!  
Required materials: [materials.csv](./materials.csv)  
This 3D print is used for the locking mechanism: [Sliding Lock | Locking Latch in MakerWorld](https://makerworld.com/en/models/1879613-sliding-lock-locking-latch) 

### Arcade machine dimensions:

Height: 750mm

Depth: 140mm  
Height: 230mm

#### WHEEL:

Depth: 325mm

#### WITH EVERYTHING ELSE:
