EasyRoads3D Shaders:
----------------------------

Shader packages for the built-in render pipeline, URP and HDRP are located in /Assets/EasyRoads3D/SRP Support Packages/

When no shaders are present in the project, the respective material package will auto import. 

The required materials package can be imported manually from the above mentioned path in the case that all road materials are still pink. 

For full details see the URP & HDRP Readme file in the EasyRoads3D root directory
