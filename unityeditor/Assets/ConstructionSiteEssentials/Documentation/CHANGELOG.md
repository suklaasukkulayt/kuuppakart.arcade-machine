# Changelog

## 1.0.1 — 15 September 2026

Improved the included showcase scene for Asset Store review: all 12 prefabs are presented on a ground and backdrop with a tagged MainCamera and key/fill/rim lighting. Added explicit demo-scene opening instructions and corrected the Unity verification wording in the package README.

## 1.0.0 — 15 September 2026

Initial generated submission candidate: 12 original static props, GLB and binary FBX exports, 15 reusable texture sets, 30 Unity material assets, 12 prefabs, a demo scaffold, package-local setup/validation tools and complete procedural source.

Pre-delivery corrections: stable tube frames to fix shading on wheelbarrow rim and rebar ties; closed-loop tube cap cleanup; rebar rib density reduction; physical stripe aspect correction; neutralized preview lighting; export base-color double-tint correction; relative texture paths adjusted for both standalone and Unity FBX locations; canonical binary FBX name/class separators checked against format conventions.

Native Blender file generation, independent FBX import, Unity compilation/import and publisher approval remain separate checks.

## 1.1.0 — local successor candidate, 16 October 2026

Added a true-scale 12-prop inventory gallery, two grouped detail scenes, optional static compound collider prefabs, and generated UV2 import settings. The original v1.0.1 prefab files, GUIDs, CSE_Showcase scene, material sets and FREE listing state are preserved. Candidate checks target Unity 6000.3.25f1 with Built-In rendering; this local candidate does not update the public listing.
